Punto de partida: el contorno del módulo 2

G <- read.pnm("datos/otolito_scom.pgm")@grey
binarizar <- function(G, umbral) {
  B <- ifelse(G > umbral, 0, 1)
  B[c(1, nrow(B)), ] <- 1; B[, c(1, ncol(B))] <- 1
  B
}
B <- binarizar(G, 0.35)
pix <- which(B == 0, arr.ind = TRUE)
inicio <- c(round(median(pix[, "col"])), nrow(B) - round(median(pix[, "row"])))

Más de mil puntos, separados por 1 píxel, y distintos en número para cada otolito. Para comparar individuos se necesita el mismo número de puntos en posiciones equivalentes.

Muestreo de pseudolandmarks

Abscisa curvilínea (Claude 2008, p. 52)

Como Conte() entrega un punto por píxel, basta tomar índices regularmente espaciados con seq():

¿Realmente equiespaciados?

En una grilla de píxeles un paso diagonal mide \(\sqrt{2}\) y uno horizontal 1: el muestreo por índice no es exactamente equidistante. Complemento: interpolar a lo largo del perímetro acumulado.

equiespaciar <- function(X, Y, n) {
  xy <- rbind(cbind(X, Y), c(X[1], Y[1]))               # contorno cerrado
  s  <- c(0, cumsum(sqrt(rowSums(diff(xy)^2))))         # distancia acumulada
  si <- seq(0, max(s), length = n + 1)[-(n + 1)]        # n distancias iguales
  cbind(x = approx(s, xy[, 1], si)$y, y = approx(s, xy[, 2], si)$y)
}
M2 <- equiespaciar(cont$X, cont$Y, np)
paso <- function(M) sqrt(rowSums(diff(rbind(M, M[1, ]))^2))
round(rbind(indice = summary(paso(M)), perimetro = summary(paso(M2))), 2)
#>            Min. 1st Qu. Median  Mean 3rd Qu.  Max.
#> indice    18.36   21.21  22.65 22.53   23.71 28.32
#> perimetro 16.22   22.48  22.99 22.46   23.22 24.01

Con el perímetro acumulado los tramos a lo largo del borde miden exactamente lo mismo; las cuerdas (rectas entre puntos) varían menos que con el muestreo por índice.

Radios equiangulares (Claude 2008, función 2.6)

regularradius() elige los puntos del contorno a ángulos iguales desde el centroide. Es el muestreo del Fourier de radios (polar).

rr <- regularradius(cont$X, cont$Y, np)
Xc <- mean(cont$X); Yc <- mean(cont$Y)
par(mfrow = c(1, 3), mar = c(1, 1, 2, 1))
plot(cont$X, cont$Y, type = "l", asp = 1, axes = FALSE, xlab = "", ylab = "", main = "Índice (Claude p. 52)")
points(M, pch = 21, bg = "white")
plot(cont$X, cont$Y, type = "l", asp = 1, axes = FALSE, xlab = "", ylab = "", main = "Perímetro acumulado")
points(M2, pch = 21, bg = "white")
plot(cont$X, cont$Y, type = "l", asp = 1, axes = FALSE, xlab = "", ylab = "", main = "Radios equiangulares")
segments(Xc, Yc, rr$coord[, 1] + Xc, rr$coord[, 2] + Yc, col = "grey70")
points(rr$coord[, 1] + Xc, rr$coord[, 2] + Yc, pch = 21, bg = "white")

¿Cuál usar?

Muestreo Uso Ventaja Problema
Abscisa curvilínea Fourier elíptico Puntos repartidos según la longitud del borde Requiere punto de inicio homólogo
Radios equiangulares Fourier de radios Un solo valor (r) por ángulo Pocos puntos en salientes alargadas (rostro); falla si un radio corta el contorno 2 veces

En otolitos, con rostro y antirostro marcados, se recomienda la abscisa curvilínea + Fourier elíptico (Claude 2008, secc. 5.2.1 y 5.2.3).

¿Cuántos puntos?

  • Con p puntos se estiman como máximo p / 2 armónicos de Fourier.
  • Deben bastar para seguir los detalles del borde (crenulaciones) sin sobremuestrear el ruido de los píxeles.
  • Los datos del curso usan 50 puntos por otolito (hasta 25 armónicos).

Punto de inicio y sentido

Correspondencia entre otolitos

El punto i de un otolito se compara con el punto i de los demás: todos deben comenzar en la misma zona del contorno y recorrerse en el mismo sentido.

area_con_signo <- function(M) {             # fórmula del polígono (shoelace)
  x <- M[, 1]; y <- M[, 2]
  sum(x * c(y[-1], y[1]) - c(x[-1], x[1]) * y) / 2
}
area_con_signo(M2)      # > 0: antihorario; < 0: horario
#> [1] 75101.92
antihorario <- function(M) if (area_con_signo(M) < 0) M[nrow(M):1, ] else M
iniciar_en  <- function(M, i) M[c(i:nrow(M), seq_len(i - 1)), ]   # rota el orden
# Criterio simple: comenzar en el punto más a la izquierda (otolitos orientados igual)
M2 <- antihorario(M2)
M2 <- iniciar_en(M2, which.min(M2[, 1]))

Conte() recorre el borde en sentido horario en la matriz (fila hacia abajo); al pasar a coordenadas del gráfico (y hacia arriba) el sentido se invierte. Los contornos de merluza del curso son antihorarios y comienzan en el punto más a la izquierda: se adopta esa misma convención.

Efecto del punto de inicio

par(mfrow = c(1, 3), mar = c(1, 1, 2, 1))

  plot(Mi, type = "l", asp = 1, axes = FALSE, xlab = "", ylab = "", main = paste("inicio en el punto", i))

Misma forma, matrices distintas. La normalización de Fourier (módulo 5) corrige parte del problema, pero conviene digitalizar siempre desde la misma zona y con la misma orientación (otolito izquierdo, cara interna, rostro a la izquierda).

Descriptores de tamaño y forma

Tamaño: área, perímetro, largo y ancho

mm_por_pixel <- NA                 # p. ej. 1 / escala_px; NA = trabajar en píxeles
xy <- cbind(cont$X, cont$Y)
if (!is.na(mm_por_pixel)) xy <- xy * mm_por_pixel

perimetro <- sum(paso(xy))
area      <- abs(area_con_signo(xy))
# Largo = diámetro de Feret (máxima distancia); ancho = perpendicular al largo
d  <- as.matrix(dist(xy)); ij <- which(d == max(d), arr.ind = TRUE)[1, ]
v  <- xy[ij[2], ] - xy[ij[1], ]; a <- atan2(v[2], v[1])
xr <- xy %*% matrix(c(cos(a), -sin(a), sin(a), cos(a)), 2, 2)   # largo sobre el eje x
largo <- diff(range(xr[, 1])); ancho <- diff(range(xr[, 2]))
round(c(area = area, perimetro = perimetro, largo = largo, ancho = ancho), 1)
#>      area perimetro     largo     ancho 
#>   75442.0    1243.0     438.2     277.9

El área por fórmula del polígono coincide con el conteo de píxeles del módulo 2 (sum(B == 0)) salvo por el borde.

Índices de forma

indices <- c(circularidad    = perimetro^2 / area,          # 4π ≈ 12.6 en un círculo
             redondez        = 4 * area / (pi * largo^2),   # 1 en un círculo
             rectangularidad = area / (largo * ancho),      # 1 en un rectángulo
             elipticidad     = (largo - ancho) / (largo + ancho),
             aspecto         = largo / ancho)
round(indices, 3)
#>    circularidad        redondez rectangularidad     elipticidad         aspecto 
#>          20.481           0.500           0.619           0.224           1.577

Las definiciones de estos índices varían entre autores y programas (p. ej., ImageJ define circularidad como \(4\pi A / P^2\)). Indique siempre la fórmula usada. Son adimensionales, pero resumen la forma en un número: no permiten reconstruirla (para eso, Fourier).

Del archivo de imagen a la matriz de 50 puntos

Una función para una imagen

contorno_desde_imagen <- function(archivo, umbral = 0.35, np = 50) {
  img <- read.pnm(archivo)
  if (is(img, "pixmapRGB")) img <- as(img, "pixmapGrey")
  B   <- binarizar(img@grey, umbral)
  pix <- which(B == 0, arr.ind = TRUE)
  ini <- c(round(median(pix[, "col"])), nrow(B) - round(median(pix[, "row"])))
  ct  <- Conte(ini, B)
  M   <- equiespaciar(ct$X, ct$Y, np)
  M   <- antihorario(M)
  iniciar_en(M, which.min(M[, 1]))
}
